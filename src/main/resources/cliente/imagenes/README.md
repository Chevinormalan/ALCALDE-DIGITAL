# Imágenes de ejecución

Los 148 PNG de ejecución de la entrega 1 están en `../arte/`, agrupados por actores, acciones, efectos, iconos, objetos y tiles. Su `index.html` muestra todos los recursos y `INVENTARIO.txt` registra dimensiones. Las carpetas antiguas de imágenes se conservan para futuras integraciones.

Los archivos maestros permanecen, desde la raíz del proyecto, en:

`../Diseño Visual y Dirección de Arte/`

Cada recurso integrado debe registrar origen, dimensiones, uso, pivote y, cuando aplique, licencia.
