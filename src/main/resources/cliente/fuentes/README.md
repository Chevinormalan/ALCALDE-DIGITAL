# Fuentes

Pixelify Sans está empaquetada como `PixelifySans.ttf`, sin instalación del sistema ni descarga durante el juego.

Autoría: The Pixelify Sans Project Authors. Licencia SIL Open Font License 1.1: `OFL-PixelifySans.txt`.
Origen: https://github.com/google/fonts/tree/main/ofl/pixelifysans

`TemaPixel` carga y conserva las variantes de tamaño. Se verifican tildes, ñ y signos de apertura; los símbolos que no incluye la familia (por ejemplo, flechas) usan la fuente lógica Dialog con suavizado desactivado.
