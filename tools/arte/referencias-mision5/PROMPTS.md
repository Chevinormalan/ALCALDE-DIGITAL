## Interior del servidor

Production pixel-art game background inside a corrupted computer server for Alcalde Digital. Landscape 16:9. Reference office defines visual style. Deep purple #21152F, violet #604077, lavender #BD91D5, gold #F4CB6A circuits, cyan terminals. Head-on stage, motherboard floor, server towers on side edges. Upper center empty dais for separately animated server boss. Lower center VERY LARGE dark empty flat rectangle x20%-80% y45%-85% for arena drawn in code. No characters, hearts, projectiles, text or HUD. Detailed discrete pixel texture, angular shapes. Whimsical malfunctioning data-center interior, high readability.

## Servidor y ataques

Production game sprite sheet on true transparent background for Alcalde Digital. 4 columns x 3 rows EXACTLY equal cells, 12 full sprites with wide margins per cell. Each row one consistent subject with four consecutive animation frames. ROW1: corrupted central server from reference office, anthropomorphic hexagonal purple server tower with cyan screen face angry then flicker then open vents then recovering, gold warning lamps. ROW2: original computer virus projectile, pixelated magenta spiked data bug with rotating small square particles, four frames rotating/flickering. ROW3: original signal emitter cannon, purple hexagonal router drone with gold casing and cyan aperture, four frames charging/open/fire/recover. Compact squat proportions and hard pixel edges, detailed discrete pixel art consistent with reference, palette #21152F #604077 #BD91D5 gold #F4CB6A plus cyan and magenta. No people, no text, no lettering, no bones or skulls, no HUD, no shadows between cells. Sprites centered and same scale within their row. Transparent actual background.
